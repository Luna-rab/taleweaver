# 取得元（api.gatcg.com）のデータ

実データで確かめた事実。数は 2026-11-28 に全カード（2,535 枚）を取得して数えた。

## id

- カードやエディションの id（`uuid`）は振り直されることがある。そのため、id で見つからなければ slug で同じものを探す。
- 裁定には id がない。

## 表記の揺れ

infrastructure で直してから domain に渡す。

| 項目                              | 取得元の値                                       | 直し方                                     |
| --------------------------------- | ------------------------------------------------ | ------------------------------------------ |
| 裁定の日付（`rule[].date_added`） | 0 で埋めていないものがある（`2023-2-6`）         | `YYYY-MM-DD` にそろえる                    |
| 題のない裁定（`rule[].title`）    | 空文字                                           | `null` にする                              |
| X コスト                          | `cost.value` が `"X"`、`cost_memory` などは `-1` | `"X"` で渡す                               |
| speed                             | 真偽値                                           | `true` を `fast`、`false` を `slow` にする |

属性・class・type は大文字で返る。

## 実在するデータ

規則に見えても、次のデータは取得元に実在するので拒否しない。

- 既定のエディション（`is_default`）がないカード（3 枚）
- 同じ名前のカード（重複は 17 件）
- 属性が空のカード（4 枚）
- 行き先のない参照。5 件が `crystal-mastery` を指し、そのカードは取得元にない。こちらでは書き換えない。公式が直したのか、こちらの書き換えが残っているだけなのかを区別できなくなるため。

## セット

- セットだけを返す API はない（`/sets` は 404）。セットは `editions[].set` に埋め込まれて返る。全ページを取り終えないと、全部のセットはそろわない。
- 64 セットあり、同じ id で中身が食い違うものはない。
- 略号（`prefix`）は一意だが、空白を含むものがある（`DOA 1st`、`DTR Alter` など 14 個）。
- 言語は `EN` と `CN`。
- 発売日（`release_date`）は時刻つき（`2024-01-24T00:00:00`）で返る。日付に直す。

## 画像

- `editions[].image` は `/cards/images/<id>.jpg` の形のパスで、api.gatcg.com の下にある。エディションの間で重なるパスはない。
- 画像は `ETag` を返す。`If-None-Match` を付けて取得すると、変わっていなければ 304 になる。
- `Cache-Control: max-age=14400` を返す。

## 両面カード

裏面はカードの項目ではなく、エディションの `other_orientations` に入っている。

## エラッタ

エラッタは、題に ERRATA を含む裁定として出る（例: `ERRATA`、`ERRATA, DTR`）。
